# 写真・動画の保存先の比較

2026年9月時点の料金で比較。記録(場所・日付・コメント・リアクション)は今のまま
CloudKit に置き、**写真と動画だけ**をどこに置くかを検討する。

## 前提(使い方の見積もり)

- 写真 1枚 ≒ 0.5MB(長辺2000px・JPEG 0.7 に圧縮済み)
- 動画 1本 ≒ 30〜40MB(720p・最大60秒)
- 課金ユーザー1人あたり: 写真300枚+動画20本 ≒ **約0.75GB**
- 無料ユーザーは1か所3枚まで・動画なし → 1人あたり数十MB

## 比較

| | 利用者のiCloud(いま) | Cloudflare R2 | Firebase Storage | Supabase Storage |
|---|---|---|---|---|
| 保存の料金 | 0円(利用者の容量を使う) | $0.015/GB・月(10GBまで無料) | Blaze必須。5GBまで無料、以降従量 | Pro $25/月に100GB込み、超過 $0.021/GB |
| 見るときの転送料 | 0円 | **0円** | 1日1GBまで無料、以降従量 | 250GB込み、超過 $0.09/GB |
| 課金ユーザー1,000人(750GB)の目安 | 0円 | **約$11/月** | 保存約$20+転送量次第で数十〜$100超/月 | $25+約$14+転送量次第 |
| ログイン | 不要(強み) | **必要** | 必要 | 必要 |
| 利用者の容量 | 招待した側(オーナー)のiCloudを消費。無料は5GB | 消費しない | 消費しない | 消費しない |
| App Storeのプライバシー表示 | データ収集なし | 写真・動画を収集(アカウントに紐づく) | 同左 | 同左 |
| 追加で必要なもの | なし | 認証つきのアップロード用サーバー(Workers)、アカウント削除機能 | アカウント削除機能 | アカウント削除機能 |
| Android・Web版 | 不可 | 可 | 可 | 可 |

## 外部クラウドにする場合に必ず必要になること

1. **Sign in with Apple** などのログイン(誰の写真かを確かめるため)
2. **アカウント削除機能**(アカウントを作れるアプリは、アプリ内から削除できないと審査に通らない)
3. プライバシーポリシーの更新と、App Store のプライバシー表示の変更
4. 共有相手だけが見られるようにするアクセス制御(記録帳ごとの権限)

## 推奨

- **外部にするなら Cloudflare R2**。転送料が0円なので、動画を何度見られても費用が増えない。
  課金ユーザー1,000人でも月$11程度で、月額300円×1,000人の売上に対して無視できる額
- 構成: 記録はCloudKitのまま、写真・動画だけR2。ログインは Sign in with Apple(ワンタップ)。
  アップロード先の発行は Cloudflare Workers で行う(利用者ごとの署名つきURL)
- 実装の順番: ①Sign in with Apple ②Workers(署名つきURLの発行・権限確認) ③アプリの保存/読み込みを差し替え
  ④既存の写真の移行 ⑤アカウント削除 ⑥プライバシー表示の更新
